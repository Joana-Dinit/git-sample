## ⚙️ Local Development

Follow these steps to set up and run the project locally on your machine.

### Prerequisites

You need a web browser and a code editor (like [VS Code](https://visualstudio.com)). If you are using a framework, ensure you have [Node.js](https://nodejs.org) installed.

### Installation & Running

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the project directory:**
   ```bash
   cd your-portfolio-repo
   ```

3. **Launch the site:**
   * *For basic HTML/CSS/JS:* Open `index.html` directly in your browser, or use the VS Code **Live Server** extension.
   * *For React/Vue/Next.js:* Run the commands below:
     ```bash
     npm install
     npm run dev
     ```
